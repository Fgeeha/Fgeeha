## Стек

**Языки:** Python, Go, PHP

**Backend:** Django, FastAPI, Flask, aiogram, maxapi

**AI/ML:** RAG, LangChain, Ollama, PyTorch, Keras, pandas, NumPy

**Базы данных:** PostgreSQL, MySQL, SQLAlchemy 2, Alembic, ChromaDB

**Инфраструктура:** Docker, Docker Compose, Linux, GitHub Actions, Gitea Actions, Trivy

**Мониторинг:** Prometheus, Grafana, TensorBoard

**Десктоп:** PyQt6, Tkinter, Fyne

**Инструменты:** Git, Make, uv, ruff, pytest, pre-commit, Nginx, Caddy, Redis, Celery

**Домашний сервер:** Ryzen 7 7700 · RTX 5070 Ti · 96 ГБ RAM · Ubuntu 25.10 —
модели, базы и мониторинг сначала запускаются здесь, и только потом в облаке.

### Экосистема мессенджера MAX

Боты и инструменты для [MAX](https://max.ru) — от переиспользуемого шаблона
проекта до GitHub Action, который присылает статус сборки прямо в чат.

| Проект                                                                                   | Что делает                                                                          | Технологии                                        |
| ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ | ------------------------------------------------- |
| [max-ollama](https://github.com/Fgeeha/max-ollama)                                       | Чат с локальными моделями Ollama внутри MAX: потоковые ответы, выбор модели, vision  | Python, maxapi, Ollama, Docker                    |
| [template-max-bot-github-gitea](https://github.com/Fgeeha/template-max-bot-github-gitea) | Production-шаблон бота с CI/CD сразу под GitHub Actions и Gitea                      | Python, maxapi, uv, Docker, polling и webhook     |
| [max-action](https://github.com/Fgeeha/max-action)                                       | GitHub Action для уведомлений о сборках, деплоях и PR в MAX                          | Go, без зависимостей, MAX Bot API                 |
| [base-max-bot](https://github.com/Fgeeha/base-max-bot)                                   | Справочный бот с админкой внутри бота, рассылками и email-уведомлениями              | Python, SQLAlchemy 2, asyncpg, Alembic, pytest    |
| [ID Helper Bot](https://github.com/Fgeeha/ID-Helper-Bot-max)                             | Показывает `user_id`, `chat_id` и идентификаторы медиа при разработке ботов          | Python, maxapi, Docker, uv                        |
